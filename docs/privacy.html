DeskGlow

DeskGlow 개인정보처리방침

DeskGlow는 휴대폰에서 사용자가 연결한 Windows PC를 제어하는 앱입니다.

PC 연결과 설정

앱은 연결에 필요한 PC 주소와 페어링 정보를 휴대폰에 저장합니다. PC 제어 명령과 버튼 이름은 사용자가 연결한 PC와 로컬 네트워크를 통해 주고받습니다. Windows 앱은 작업 배치와 버튼 이름을 PC에 저장합니다. DeskGlow는 이 정보를 운영자 서버로 전송하지 않습니다.

카메라와 이미지

카메라는 QR 연결을 선택했을 때 연결 정보를 읽는 데 사용합니다. 사용자가 배경이나 버튼 이미지로 선택한 사진은 휴대폰에 저장해 표시합니다.

설정 삭제 및 문의

Android 설정에서 DeskGlow의 앱 데이터를 지우면 휴대폰에 저장된 연결 정보와 꾸미기 설정이 삭제됩니다. 문의는 DeskGlow GitHub에서 받습니다.
