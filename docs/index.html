작업 배치 복원

여러 모니터에 놓인 창을 저장하고 휴대폰 버튼으로 다시 엽니다.

PC 제어

세로 슬라이더로 음량을 조절하고, 음소거하거나 PC를 절전 모드로 전환합니다.

내 화면 꾸미기

배경과 버튼 이미지를 설정하고, 버튼 이름과 순서를 편집합니다.

연결 방법

  1. Windows에서 DeskGlow를 실행합니다.
  2. Android와 PC를 같은 로컬 네트워크에 연결합니다.
  3. Android 앱의 QR 연결로 Windows 화면의 QR을 스캔합니다.
